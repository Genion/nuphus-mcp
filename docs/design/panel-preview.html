Behavior
写入操作如何被拦截
「确认」态的工具被 Agent 调用时，返回 isError 并附确认指引 —— Agent 必须带上 "confirm": true 重试才放行。行为与主项目审批流同源：由策略决定，不由模型自觉。
# Agent 调用 desktop_mouse（click）→ 被拦截： { "isError": true, "content": [{ "type": "text", "text": "Write tool requires confirmation. Retry with \"confirm\": true" }] } # Agent 带 confirm 重试 → 放行执行
